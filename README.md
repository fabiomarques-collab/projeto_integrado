# Sistema de consulta de preços dos serviços do Balneário Dr. Mário Mourão em Poços de Caldas.

# Sobre o projeto

Este projeto foi desenvolvido para Curso de Análise e Desenvolvimento de Sistemas da UNIFEOB,
como parte do PROJETO INTEGRADO do módulo de Desenvolvimento de Sistemas,
visando aplicar os princípios aprendidos de Lógica de Programação e 
Programação Orientada a Objetos, utilizando a Linguagem Java.

O sistema permite realizar o identificação do cliente, consultar os
serviços disponíveis e calcular o valor a ser pago de acordo com o perfil do cliente.

## ⚙️ Funcionalidades

- Identificação do cliente;
- Exibição do menu de serviços;
- Seleção de serviço;
- Exibição do serviço escolhido e valor final.

## 🛠️ Tecnologias utilizadas

- IntelliJ IDEA
- GitHub
- IF-ELSE
- SWITCH-CASE
